# 🤖 Asistente Virtual de Reuniones

Este proyecto es un asistente de AI desarrollado en Python que permite agendar reuniones mediante un chatbot.

## 🧠 Funcionalidades

- Chatbot con procesamiento de lenguaje natural
- Entrenamiento de intenciones con Keras
- Interfaz web con Streamlit
- Confirmación de reuniones simulada

## 📦 Requisitos

Instala las dependencias con:

```bash
pip install -r requirements.txt
```

## 🚀 Ejecución

1. Entrena el modelo:

```bash
python train_chatbot.py
```

2. Ejecuta la app:

```bash
streamlit run app.py
```
